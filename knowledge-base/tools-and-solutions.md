# Tools & solutions directory

This directory is the documentation layer for myHerb tools and technical work. It should explain each item without overstating maturity, ownership or commercial readiness.

## Where to explore

* Visit the [Tools & solutions page](https://www.myherb.co.il/solutions) on the main website for the current public collection.
* Use the DevSphere documentation for open-source and developer-oriented material.
* Use GitHub for source code, repository history, issues and licenses.

## Required record for each tool

Before a tool is promoted as available, document:

1. name and one-sentence purpose;
2. maturity: production, beta, prototype, experiment or third-party reference;
3. original source and repository ownership;
4. live URL and last successful test date;
5. data collected and privacy implications;
6. license and third-party dependencies;
7. support owner and recovery path;
8. whether it is free, included in another product or sold separately.

{% hint style="warning" %}
A repository, mock-up or deployment URL is not by itself proof that a tool is production-ready or commercially available.
{% endhint %}
