# Knowledge base

The knowledge base connects the existing myHerb library into practical routes. It is designed to grow without creating another disconnected site.

## Browse by need

### Learn sustainability fundamentals

Start with the existing [Sustainability Implementation Framework](../learning/sustainability-implementation-framework.md), then continue through the [Learning paths](learning-paths.md).

### Apply sustainability in a business

Use the existing [Data-Driven Sustainability Shift Guidance](../main/bookspace/myherbs-data-driven-sustainability-shift-guidance.md) as a reference. Check sources and dates before using a claim in a decision or public statement.

### Explore tools and technical work

Open the [Tools & solutions directory](tools-and-solutions.md). Technical source and history stay in GitHub; this library explains what each item is and its current status.

### Understand partnerships and collaboration

See [About myHerb Partners Network](../collaborating/about-myherb-partners-network/README.md). Partnership claims should be treated as current only when the underlying program or account has been independently verified.

### Find digital resources

Use the [Digital products](../digital-products/README.md) catalog. It separates free public references, drafts, prototypes and future paid products.

## Expansion rule

New material should be added to this canonical hub first. A separate public site should be created only when it has a distinct audience, owner and maintenance plan that cannot be served by a section here.
