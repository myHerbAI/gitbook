# Start here

Welcome to the myHerb knowledge hub. This library brings the existing documentation, sustainability resources, tools and learning material into one navigable place while preserving the history and authorship of the original work.

Use this hub to:

* learn the foundations of practical sustainability;
* explore myHerb tools and documented solutions;
* follow structured learning paths;
* understand which resources are public, in development or planned;
* find the original source and status of important material.

## Choose a path

* **I want an answer or guide:** go to the [Knowledge base](../knowledge-base/README.md).
* **I want a structured learning route:** open [Learning paths](../knowledge-base/learning-paths.md).
* **I want to explore tools:** use the [Tools & solutions directory](../knowledge-base/tools-and-solutions.md).
* **I want a template, course or digital resource:** check [Digital products](../digital-products/README.md) and its availability status.
* **I want to understand authorship or reliability:** read [Content status and provenance](content-status-and-provenance.md).

{% hint style="info" %}
This hub is the documentation layer. Product pages, checkout and customer delivery belong on the main myHerb website and are linked only after they have been verified.
{% endhint %}

## What is changing

The library is being organized around clear journeys instead of separate, overlapping documentation sites. Existing pages remain available while the new navigation is introduced. Consolidation does not transfer authorship and does not turn a draft, prototype or historical record into a released product.
